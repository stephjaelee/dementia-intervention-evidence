# 中期混合型痴呆的循证干预措施

本资料库包含关于中期痴呆（MMSE 13-17）合并阿尔茨海默病/血管病理的生活方式和药物干预的综合研究。

## 背景

本研究为以下患者情况编制：
- 中期痴呆（MMSE 13-17）
- 既往小中风
- 高胆固醇
- 可能的混合型阿尔茨海默病和血管性痴呆

## 主要发现

### 有效的干预措施

1. **运动**（效应量：0.30-0.46）- 与FDA批准药物效果相当
2. **胆固醇管理**（LDL <70 mg/dL）- 复发性中风风险降低22-28%
3. **认知刺激治疗**（效应量：0.35-0.58）- 与药物疗效相当
4. **血压控制**（<130 mmHg）- 轻度认知障碍风险降低19%

### 合理预期

- **目标**：减缓下降，而非逆转损伤
- **可实现**：认知下降速度减缓25-50%
- **时间线**：3-6个月可见稳定效果
