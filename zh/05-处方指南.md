# 处方指南：具体可行的干预措施

*基于临床试验方案和指南推荐*

---

## 概述：多模式处方

| 领域 | 目标 | 证据基础 |
|------|------|---------|
| 胆固醇 | LDL <70 mg/dL | AHA/ASA指南；SPARCL、TST试验 |
| 运动 | 中等强度有氧150分钟/周 | WHO指南；荟萃分析 |
| 纤维 | 总量25-30g/天；可溶性5-10g | 荟萃分析；FDA推荐 |
| 血压 | <130/80 mmHg | SPRINT-MIND |

---

## 处方1：胆固醇管理

### 目标

| 指标 | 目标 | 理由 |
|------|------|------|
| LDL-C | **<70 mg/dL** | 二级中风预防标准 |
| 百分比降低 | **≥50%** | 高强度他汀效果 |
| 较低可接受 | 55-70 mg/dL | 安全；额外获益18-26% |
| 避免 | <30 mg/dL | 额外获益有限 |

### 药物方案

#### 第1步：高强度他汀

| 选择 | 剂量 | 预期LDL降低 |
|------|------|------------|
| 阿托伐他汀 | **80 mg 每日** | 50-55% |
| 瑞舒伐他汀 | **40 mg 每日** | 50-55% |
| 替代：阿托伐他汀 | 40 mg 每日 | 40-50% |

*注：SPARCL试验使用阿托伐他汀80mg*

#### 第2步：如LDL仍>70 mg/dL

| 添加 | 剂量 | 额外降低 |
|------|------|---------|
| **依折麦布** | 10 mg 每日 | 15-20% |

#### 第3步：如仍高于目标（极高危）

| 添加 | 剂量 | 额外降低 |
|------|------|---------|
| 依洛尤单抗（Repatha） | 140 mg 皮下注射 每2周 | 50-60% |
| 或 阿利西尤单抗（Praluent） | 75-150 mg 皮下注射 每2周 | 50-60% |

### 监测计划

| 时间点 | 操作 |
|--------|------|
| 基线 | 空腹血脂谱、肝功能检查 |
| 4-6周 | 复查血脂；评估耐受性 |
| 3个月 | 如调整剂量则查血脂；必要时查肝功能 |
| 每6-12个月 | 维持期监测 |

### 安全监测

| 关注点 | 处理 |
|--------|------|
| 肌痛（肌肉疼痛） | 查肌酸激酶；考虑换用其他他汀 |
| 肝酶>3倍正常值上限 | 停用他汀；复查；可能以较低剂量重新开始 |
| 记忆力投诉 | 重新评估；证据显示无因果关系 |

## 处方2：运动计划

### 每周结构

| 日期 | 活动 | 时长 | 强度 |
|------|------|------|------|
| 周一 | 有氧（步行） | 30-45分钟 | 中等 |
| 周二 | 力量+平衡 | 30-45分钟 | 轻-中 |
| 周三 | 有氧（骑车/步行） | 30-45分钟 | 中等 |
| 周四 | 休息或轻度拉伸 | 20分钟 | 轻度 |
| 周五 | 有氧+力量联合 | 45-60分钟 | 中等 |
| 周六 | 有氧（户外步行） | 30-45分钟 | 中等 |
| 周日 | 平衡/太极 | 20-30分钟 | 轻度 |

**每周总计**: ~150-180分钟有氧 + 2-3次力量训练

### 心率目标

#### 计算方法（Karvonen公式）

```
目标心率 = (最大心率 - 静息心率) × 强度% + 静息心率
最大心率 = 220 - 年龄
```

#### 75岁示例

| 参数 | 数值 |
|------|------|
| 估计最大心率 | 145 次/分钟 (220 - 75) |
| 假设静息心率 | 70 次/分钟 |
| 心率储备 | 75 次/分钟 (145 - 70) |

| 强度水平 | 心率储备% | 目标心率范围 |
|---------|----------|-------------|
| 轻度（热身） | 40-50% | 100-108 次/分钟 |
| **中等（目标）** | **50-70%** | **108-123 次/分钟** |
| 剧烈（需获许可） | 70-85% | 123-134 次/分钟 |

**简化目标**: 运动时心率**100-120 次/分钟**

#### 如服用β受体阻滞剂

β受体阻滞剂会降低最大心率。使用：
- **RPE（自觉用力程度）**: 目标6-20量表的12-14
- **说话测试**: 能说短句但不能唱歌

### 运动进阶

#### 第1阶段：第1-4周（适应期）

| 参数 | 处方 |
|------|------|
| 频率 | 3天/周 |
| 时长 | 20-30分钟 |
| 强度 | 50-60% 心率储备（100-115次/分钟）或 RPE 11-12 |
| 类型 | 平地步行 |
| 监督 | 必需 |

#### 第2阶段：第5-12周（提升期）

| 参数 | 处方 |
|------|------|
| 频率 | 4天/周 |
| 时长 | 35-45分钟 |
| 强度 | 60-70% 心率储备（115-123次/分钟）或 RPE 12-14 |
| 类型 | 步行 + 固定自行车 |
| 增加 | 抗阻训练2次/周 |

#### 第3阶段：第13周及以后（维持期）

| 参数 | 处方 |
|------|------|
| 频率 | 5天/周 |
| 时长 | 45-60分钟 |
| 强度 | 60-70% 心率储备 或 RPE 12-14 |
| 类型 | 多样化（步行、骑车、如可能则游泳） |
| 继续 | 抗阻2次/周；平衡2-3次/周 |

### 力量训练方案

| 动作 | 组数 × 次数 | 备注 |
|------|------------|------|
| 坐站起立 | 2 × 10 | 从椅子起立，尽量不用手 |
| 墙壁俯卧撑 | 2 × 10 | 进阶到扶台面，再到地面 |
| 坐姿抬腿 | 2 × 10 每腿 | 如可耐受可加踝部负重 |
| 手臂弯举 | 2 × 10 每臂 | 1-2.5公斤哑铃 |
| 站立提踵 | 2 × 10 | 扶椅保持平衡 |
| 坐姿划船（弹力带） | 2 × 10 | 弹力带固定 |

**进阶**: 当10次变得容易时，增加0.5-1公斤或增加阻力

### 平衡训练方案

| 动作 | 时长 | 频率 |
|------|------|------|
| 单腿站立 | 每腿30秒 | 每天 |
| 脚跟脚尖走 | 10步 | 3次/周 |
| 侧向跨步 | 每方向10步 | 3次/周 |
| 太极或类似运动 | 20-30分钟 | 2次/周 |

### 安全要求

| 要求 | 执行 |
|------|------|
| **监督** | 始终有人在场 |
| **环境** | 清除障碍物；防滑地面 |
| **鞋子** | 支撑性好、防滑的鞋 |
| **水分** | 运动前、中、后补水 |
| **停止信号** | 胸痛、严重气短、头晕 → 立即停止 |
| **医学许可** | 开始前需医生批准 |

## 处方3：膳食纤维

### 每日目标

| 纤维类型 | 目标 | 主要功能 |
|---------|------|---------|
| 总纤维 | **25-30 g/天** | 整体健康 |
| 可溶性纤维 | **5-10 g/天** | 降低LDL |

#### 早餐（~8-10g纤维）

| 食物 | 量 | 纤维 |

### 车前子补充方案

**如膳食纤维不足，添加：**

| 时间 | 剂量 | 说明 |
|------|------|------|
| 早餐前 | 1汤匙车前子加240毫升水 | 立即饮用；随后多喝水 |
| 晚餐前 | 1汤匙车前子加240毫升水 | 同上 |

**重要**:
- 从1茶匙开始，1-2周内逐渐增加
- 必须充足饮水（每天8-10杯）
- 在服用车前子1小时前或2-4小时后服用药物

## 处方4：血压管理

### 目标

| 参数 | 目标 |
|------|------|
| 收缩压 | **<130 mmHg** |
| 舒张压 | **<80 mmHg** |
| 如虚弱的替代目标 | <140/90 mmHg |

*基于SPRINT-MIND：强化血压控制显示MCI风险降低19%*

### 监测

| 频率 | 方法 |
|------|------|
| 每周 | 家庭血压监测 |
| 每次就诊 | 诊室测量 |

**注意**: 体位性低血压（站立时头晕）- 增加跌倒风险

## 监测和随访计划

| 时间点 | 检查/评估 |
|--------|----------|
| **基线** | MMSE/MoCA、血脂谱、血压、体重 |
| **第4-6周** | 血脂谱（他汀反应） |
| **第3个月** | MMSE/MoCA、血压、体重、运动日志审查 |
| **第6个月** | 血脂谱、MMSE/MoCA、功能评估 |
| **第12个月** | 全面重新评估 |

### 成功指标

| 指标 | 目标 |
|------|------|
| LDL-C | 维持<70 mg/dL |
| 运动依从性 | ≥80%处方次数 |
| MMSE下降 | <2分/年（vs预期3-4分） |
| ADL维持 | 稳定或改善 |
| 跌倒 | 减少或零 |

## 何时联系医疗服务提供者

| 情况 | 行动 |
|------|------|
| 严重肌肉疼痛 | 24-48小时内联系 |
| 运动时胸痛 | 立即停止；如持续则就医 |
| 跌倒 | 下次就诊时报告；可能需要物理治疗评估 |
| 突然意识改变 | 当天联系 |
| 一侧新发无力 | 拨打急救电话 - 可能是中风 |
